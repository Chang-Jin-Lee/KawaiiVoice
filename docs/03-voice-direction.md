# 음성 디렉션

> **가장 중요한 전제: 음성 변환은 *음색*을 바꾸지만 *연기*를 바꾸지 않는다.**
> 남성적 억양·말투로 읽으면 결과물은 "여성 음색을 가진 남성 연기"가 된다.
> 최종 품질의 절반 이상이 이 문서에서 결정된다. 파라미터 튜닝으로 만회할 수 없는 영역이다.

## 30세 남성 성우 디렉션

### 발성

| 지시 | 이유 |
|---|---|
| **흉성(체스트) 비중을 줄이고 가볍게** | 흉성 배음은 변환 후에도 "남성적 두께"로 남는다 |
| **가성까지 억지로 올리지 말 것** | 가성은 배음 구조가 무너져 변환 품질이 오히려 떨어진다. 피치는 RVC가 올린다 |
| **평소보다 살짝 높은 편안한 음역에서 일정하게** | 자동 피치 시프트가 ±12로 클램프되므로, 극단적 저음은 목표 음역에 못 닿는다 |
| **마이크 거리 일정 유지** | 거리 변화 = 음압·근접효과 변화 → 파일 간 음색 흔들림의 주원인 |

### 연기 — 여고생 캐릭터로서

- **말끝 처리**: 종결어미를 남성 화법으로 떨어뜨리지 말고 캐릭터 화법으로. ("~했다" 톤 → "~했어", "~하는데?")
- **문장 끝 억양**을 남성 평서문의 하강조로 닫지 않는다. 한국어에서 성별 인지는 어미 억양에 크게 의존한다.
- **감정·호흡은 과장해서 명확하게.** 변환 과정에서 미세한 뉘앙스는 일부 깎인다. 원본이 애매하면 결과는 무표정해진다.
- 리액션(놀람·아픔·기합)은 대사보다 더 과하게. 서브컬쳐 게임의 캐릭터성은 여기서 나온다.

### 녹음 규격

| 항목 | 값 |
|---|---|
| 포맷 | WAV 48kHz / 24bit 모노 |
| 레벨 | 피크 -6dBFS 여유, **클리핑 절대 금지** (클리핑은 변환으로 복구 불가) |
| 처리 | **컴프레서·EQ·리버브 걸지 않은 드라이 원본.** RVC는 깨끗한 입력을 전제로 한다 |
| 테이크 | 대사별 3테이크 이상 (변환 후 어느 테이크가 살아남을지 사전에 알 수 없다) |
| 환경 | 룸 반사 억제. 리버브는 변환 품질을 직접 떨어뜨린다 |

**클리핑과 리버브 두 가지만 지켜도 후반 작업량이 크게 줄어든다.**

## 탑다운 슈터 특성 반영

이 장르는 대사 구성이 일반 어드벤처와 다르다.

| 유형 | 특징 | 디렉션 |
|---|---|---|
| **전투 바크** ("뒤에!", "재장전!", "맞았어!") | 0.3~1초, 반복 재생, 최다 물량 | 타이밍이 곧 게임 피드백. 짧고 명료하게. 앞 무음 최소화 |
| **피격·사망** | 비명·신음 | 무성음 비중이 높아 변환이 가장 불안정한 구간. 테이크를 넉넉히 |
| **스킬·궁극기** | 기합, 대사 겹침 | BGM·SFX에 묻히므로 명료도 우선 |
| **컷신·대화** | 긴 문장, 감정 | 음색 일관성이 가장 중요. 같은 세션에서 연속 녹음 |

**주의: 짧은 바크가 RVC에서 가장 어렵다.** F0 추출에 필요한 유성음 구간이 짧아 피치 추정이 불안정하고, `--proposed_pitch`의 중위 F0 계산도 표본이 부족해진다. 실제로 코드에는 이런 방어 로직이 있다:

```python
if len(valid_f0) < 2:
    up_key = 0          # 유성음이 부족하면 시프트를 포기한다
```

즉 **아주 짧거나 무성음 위주인 바크는 피치 시프트가 아예 걸리지 않을 수 있다.** 대책:
- 바크 파일을 개별로 자르지 말고 **앞뒤 여유를 둔 긴 구간으로 변환한 뒤 잘라낸다** → F0 추정 표본 확보
- 또는 짧은 바크만 `--proposed_pitch` 없이 고정 `--pitch` 값으로 별도 배치 처리
- 비명·신음처럼 유성음이 희박한 소스는 변환 대신 **타겟 여성 화자에게 직접 녹음받는 것**을 검토 (물량이 적어 현실적이다)

## 타겟 여성 화자 섭외 시

- **단일 화자.** 여러 명을 섞으면 음색이 평균화된다.
- 녹음 내용에 **외침·기합·신음**을 반드시 포함. 조용한 낭독만으로 학습하면 전투 대사에서 무너진다.
- 남성 성우와 **동일한 마이크·동일 환경**이면 도메인 갭이 줄어 변환이 안정된다.

## 캐릭터별 음색 분리

여러 캐릭터가 필요하면 선택지는 두 가지다.

| 방식 | 장점 | 단점 |
|---|---|---|
| **캐릭터별 별도 RVC 모델** | 음색 구분이 확실 | 화자별 데이터셋 확보 비용 |
| 단일 모델 + 피치·포먼트 변주 | 저렴 | 같은 사람이 연기한 티가 남는다 |

서브컬쳐 게임에서 캐릭터 목소리 구분은 상품성에 직결되므로 **주요 캐릭터는 별도 모델**을 권한다. 단역·시스템 보이스는 변주로 처리해도 무리 없다.
